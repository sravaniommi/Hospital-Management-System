# Hospital Management System

A web-based Hospital Management System developed using Django and Python. 
This project helps manage hospital activities such as doctors, patients, 
appointments, and user authentication through a simple and user-friendly interface.

## Features

- User Login and Authentication
- Doctor Management
- Patient Management
- Appointment Management
- Doctor and Patient Information
- Admin Management
- Responsive Web Interface
- Django-based Backend
- Database Management using SQLite

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- VS Code
- Git & GitHub
